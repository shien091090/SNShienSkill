# `@ai` 圖片: prompt 怎麼寫

階段 4 標了 `@ai` 的圖, 到 build 前要變成實際檔案。這份講怎麼把 SLIDES.md 的「意象 / 呈現」描述轉成可用的 prompt。

生圖本身不在 skill 範圍 — 使用者可能用任何工具。**skill 的工作是產出一份可以直接複製去用的 prompt 清單。**

## 1. 三條通則

**(1) 圖內一律不含文字**

生圖模型畫中文幾乎必壞 (變成偽漢字)。需要標籤的圖, 文字用 `decor` role 疊在 pptx 上 (見 `formats.md`), 這樣還能隨時改字。

**(2) 圖內不含箭頭等指示符號**

箭頭用 PowerPoint 內建圖案畫更乾淨也改得動, 一樣走 `decor`。而且生圖模型**很愛自己補箭頭**, 負向詞要明寫 — 只是不提是不夠的。

**(3) 成對的前後對照圖要用參考圖, 不能各生各的**

「之前 vs 之後」「A 派 vs B 派」這種成對圖, text-to-image 跑兩次幾乎不可能保持構圖一致。做法是**先生第一張, 滿意後拿它當參考圖 (image-to-image 或 edit 模式) 生第二張**, 指令直接說要改什麼、什麼不准動。

## 2. 同一份簡報的圖要風格一致

這是這一節唯一的目標。做法是**先定一段共用風格前綴, 該簡報每一張 `@ai` 圖都掛同一段**, 只有主體描述不同。

前綴要涵蓋這幾個維度, 實際的值每份簡報自己定:

| 維度 | 說明 |
|---|---|
| 繪畫風格 | 扁平向量 / 手繪 / 等距 / 照片寫實… 挑一種, 整份不混用 |
| 背景 | 通常跟 STYLE.md 的 `theme.bg` 一致, 圖才融得進投影片 |
| 色盤 | **從 STYLE.md 的 theme 導出** — 主色抄 `fg`, 強調色抄 `accent` (連 hex 一起寫進 prompt) |
| 線條與質感 | 線寬、要不要漸層、要不要陰影 |
| 留白 | 投影片上的圖通常要比插畫作品更空 |
| 調性 | 幽默 / 中性 / 嚴肅, 對應階段 4 的比喻優先序 |
| 負向詞 | 至少要有「不含文字」與「不含箭頭」, 見通則 (1)(2) |
| 長寬比 | 看該版型 image box 的比例, **不要一律 16:9** |

定好之後把前綴寫進 STATUS.md 的 log, 之後補圖或重生才有依據。

**走精準路線的圖不要生。** 流程圖、數據圖、結構示意這類本來就該畫 SVG (`@svg`), 生圖只會得到看起來很像但數字是假的東西。

## 3. 從「意象 / 呈現」轉 prompt

SLIDES.md 的圖片描述本來就分兩段, 直接對應:

- **意象** → 不進 prompt。它是給人看的, 說明這張圖為什麼存在
- **呈現** → 翻成英文進 prompt, 這段要夠具體: 有幾個人、在做什麼、手上拿什麼、表情如何、畫面怎麼分格

## 4. 交付格式

**每張一個獨立的 code block, 共用前綴直接併進去。** 不要用表格列 prompt — 使用者在 CLI 裡複製會連表格線一起複製到。

````
**1. <這張圖對應的頁>**
```
<完整 prompt: 共用前綴 + 主體描述, 整塊可直接複製>
```
````

## 5. 踩過的坑

**模型會無視負向指令。** 寫了不要文字還是可能生出英文字。不是每次都要重生 — 判斷那些字在投影片上會不會造成誤解, 不會就留著。

**「揭露」型的對照圖最難**, 就是後圖要揭露前圖被遮住的東西那種。三個原則:

1. **前圖露出的那一小部分, 材質與形狀就要跟後圖的本體一致**。否則後圖會像「換了一個東西」而不是「揭露」 — 這是最常失敗的一點
2. **不准變的東西要正反各講一次**: 先正面寫 `exactly the same size and position`, 再負面寫 `do not make it bigger and do not move it`。只寫一邊模型會飄
3. **程度的加強用材質或密度表達, 不要用尺寸**。尺寸一變就跟前一張對不上, 而且「原來它是實心的」通常比「它更大」更貼近你想講的事

**使用者自己生的圖風格可能不同。** 若發現某幾張跟其餘的風格不一致, **先問是不是刻意的**, 是就別動。

## 6. 圖進資料夾

生好的圖依用途分開放, 不要全丟同一層:

```
<NN_topic>/
  照片/      @photo  使用者提供的照片與截圖
  生成圖/    @ai     AI 生成
  示意圖/    @svg    AI 畫的向量圖
```

檔名**依頁序編號** (`11_<這頁在講什麼>.png`), 跟 SLIDES.md 的順序對得起來, 之後要換圖找得到。

生成圖**入庫前縮到 1920 寬**。投影片最寬只用到十幾英吋, 生圖工具的原始輸出常是兩三千 px, 縮完檔案大小差一半。
