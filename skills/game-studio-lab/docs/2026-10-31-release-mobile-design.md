# 發布階段: 手機觸控層與網站訊息

發布階段的補充設計(主設計見 `2026-10-29-release-stage-design.md`)。來源: 「來馬戲團看一點大場面」手動加觸控版、使用者實際看過按鈕擺位後定案的做法, 推廣成每款遊戲發布時都做。

## 為什麼

PVD計畫網站要讓手機也能玩。遊戲在網站裡跑在 iframe 中, 網站會在手機直拿、分頁被切走時送暫停訊息, 也想知道玩家有沒有玩完一局。這些都只跟「放上網站」有關, 所以放在發布階段做, 開發與打磨試玩照舊在電腦上。

## 決定

| 項目 | 做法 |
|---|---|
| 什麼時候做 | **發布階段**才加。探索 / 深掘 / 打磨的設計與 RD 都不考慮手機 |
| 加在哪 | 網站版與打磨版**兩份**都加(同 21:9 的理由: 每次發布都從打磨版重新複製, 只加網站版會被蓋掉)。之後再打磨, 設計與 RD 不管手機, 只是不能弄壞觸控層; 下次發布時 RD 補上新畫面、新按鍵的觸控設定 |
| 放在哪個檔 | `game/touch.js`(從 skill 的 `references/touch-template.js` 複製, 只改開頭的 `CONFIG`), 在 `game.js` 之後載入。遊戲邏輯只掛幾個固定鉤子 |
| 鍵盤遊戲 | 畫面上疊半透明虛擬按鈕, 輸入走遊戲和鍵盤共用的按下 / 放開入口 |
| 滑鼠遊戲 | 不加按鈕, 點擊就等於觸控; 遊戲聽滑鼠事件時把觸控轉成滑鼠事件, 遊戲區拖曳不捲動頁面 |
| 直式遊戲 | 不做觸控(網站在手機直拿時本來就不開遊戲), 只做網站訊息; `mobile` = false |
| 按鈕擺位 | 左下: 圓弧方向鍵(一圈切成上右下左四段, 段間細縫 8, 外圈直徑 336、內圈直徑 116, 可按範圍半徑 190)。右下: A(Z 鍵, 直徑 160); B(X 鍵, 直徑 124)在 A 左邊; 第三個動作鍵(空白鍵, 直徑 108)在 A 上方, 圖示依遊戲換。以 1680×720 為準, 右邊的按鈕對齊右緣 |
| 按鈕顯示 | 不能操作的畫面(自動翻頁、演出中)整組不畫; 只接受某個鍵的畫面只畫那個鍵; 用不到的鍵(例: 只有某場景用得到的動作)在其他畫面不畫 |
| 鍵帽 | 遊戲裡畫的鍵帽 Z / X / 空白 在觸控模式改成 A / B / 第三鍵圖示 |
| 何時算觸控模式 | 粗指標(`pointer: coarse`)或有觸控且沒有滑鼠懸停, 或網址帶 `?touch=1`(截圖檢查用) |
| 直拿手機 | 觸控模式下直拿 → 蓋「請把手機轉成橫向」並暫停 |
| 聲音 | 手機**不放**靜音、音量或任何聲音按鈕, 交給手機本身的靜音與音量 |
| 手機暫停 | 只有直拿與網站暫停訊息兩種, 不另放暫停按鈕 |
| 網站暫停 / 繼續 | 收 `pvd:pause` → 暫停(含音效); 收 `pvd:resume` → 顯示「點擊或按任意鍵繼續」, 點一下才繼續, 這一下不傳給遊戲。檢查 `event.origin === location.origin`。電腦版也做 |
| Esc 暫停 | 共同守則的通用鍵。遊戲自己沒有 Esc 暫停時由觸控層提供(暫停遮罩 + 「按 Esc 繼續」); 遊戲已有就關掉觸控層的這項 |
| 玩完一局 | 遊戲在「一局結束」的時間點(打磨版下載試玩紀錄的那一刻)呼叫 `PVDX.finish()`, 送 `{type:'pvd:finish'}` 給上層網站; 不在 iframe 裡就不送 |
| 支援裝置 | `info.json` 的 `mobile`: 網站版有 `touch.js` 且畫面是 21:9 → true, 否則 false |
| 按鈕有沒有蓋到資訊 | RD 不能開瀏覽器, 只能照座標推算。流程停在挑圖示時, 主 session 用無頭 Chrome 帶 `?touch=1` 逐畫面截圖給使用者看; 有蓋到就由主 session 調 `touch.js` 的 `CONFIG`(按鈕座標、各畫面顯示哪些按鈕) |

## 遊戲要掛的鉤子

鍵盤遊戲:
- 全域函式 `inputDown(鍵名)` / `inputUp(鍵名)` / `inputReset()`, 鍵盤事件也走它們; `inputDown` 開頭 `if (window.PVDX && PVDX.paused) return;`(暫停守衛寫在遊戲自己的入口, 觸控層後載入、攔截擋不住)
- 每幀: `if (!(window.PVDX && PVDX.paused)) update(dt);`, 畫完後 `if (window.PVDX) PVDX.draw(ctx);`
- 一局結束: `if (window.PVDX) PVDX.finish();`

滑鼠遊戲: 每幀與一局結束同上; 輸入不用改(暫停時觸控層在 window 捕獲階段攔下滑鼠 / 觸控事件)。

## 不做

- 存檔鍵名改成「遊戲代號:用途」(之後發布有存檔的遊戲時再一起做)
- 手機上的聲音控制、暫停按鈕
- 直式遊戲的觸控

## 留給 RD 判斷

- 各畫面該顯示哪些按鈕、方向鍵哪些畫面可斜走(照 spec 的操作與場景)
- 第三鍵圖示怎麼畫(簡單幾何, 代表該鍵的主要動作)
- 遊戲的聲音怎麼整個靜音再還原(各遊戲的音效模組介面不同)
