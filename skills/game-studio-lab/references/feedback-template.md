# feedback.md 格式

```
# 試玩回饋 <round_dir>

日期: YYYY-MM-DD
使用者選擇: continue / next / end / back-deepen / back-explore
(深掘進打磨時) 打磨底版: <款>

## <款>(例: game-a)
- 「使用者原話」 → 對應機制: ...(你的判斷, 標明是推論)

## 跨款比較
- 哪款體驗最好、為什麼(原話)

## 不好的體驗
- 「原話」 → 可能來源: ...

## 其他
- 試玩紀錄: 已搬 N 個檔到 logs/ / 無(打磨階段)
```

原則: 原話放引號裡, 你的推論另外標示; 使用者沒講的不補。
