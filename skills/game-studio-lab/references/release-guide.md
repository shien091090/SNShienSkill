# 發布用的使用者檔格式

兩個檔都是「欄位: 值」一行一個, 冒號全形半形都可以。CLI 會先驗格式, 錯了直接回 error, 不進流程。

## 發布資訊檔(release-info.md)

```
名稱: 幽影接力
代號: ghost-echo
介紹: 和過去的自己接力, 一起闖過只有合作才過得去的關卡。
```

- 三欄都必填
- 代號只能用英文小寫、數字與連字號(例 `dungeon-zoo`), 上線後不改
- 介紹 1–2 句、30–60 字(CLI 不擋字數, 由你在問的時候提醒)
- 可選 `素材: 重做`: 已經發布過的遊戲預設沿用上次定版的圖示、橫幅、色帶圖樣與主色(`release/assets/` 裡那三張圖都在), 不出方案、不停在挑選頁; 使用者明說要換圖才加這欄, 流程才重新出方案讓他挑

## 挑選結果檔(release-pick.md)

```
圖示: B
主色: 2
橫幅: A
```

- 圖示、橫幅是 A / B / C, 主色是 1 / 2 / 3, 三欄都必填; 色帶圖樣跟著主色, 不另外挑
- 看完方案改變主意、還是要上次那套: 檔案只寫 `沿用上次`, 定版時保留 `release/assets/` 原本的圖, 只更新素材資訊

## 重做意見(可選, release/options/redo-notes.md)

選 `redo` 前把使用者對上一批方案的意見照原話寫進去, 美術重做時會讀。下一次完整發布會自動清掉。
