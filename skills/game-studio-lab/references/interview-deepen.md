# 訪談指引: 深掘階段

目的: 目標體驗已經確定, 這階段要知道**哪些機制他喜歡、哪些不喜歡**, 以及原因。

## 原則
- 一次問一題, 純文字對話
- 這階段可以直接點名機制問(「蓄力這個操作你覺得怎樣?」), 因為要驗的就是機制
- 每個機制都追問「為什麼」: 喜歡是因為它強化了目標體驗, 還是別的原因?
- 他對某機制沒感覺也是答案, 照實記

## 問題主線
1. 「這幾款裡, 哪一款最有 <目標體驗> 的感覺?」(目標體驗從 hypotheses.md「已確認的體驗: 想要」來)
2. 逐款問新機制: 「<機制> 你喜歡嗎? 為什麼?」
3. 「有沒有哪個機制讓你覺得多餘、干擾, 或帶來不想要的感覺?」
4. 「如果只能留一個新機制, 你會留哪個?」
5. 最後: 「還要再深掘一輪試別的機制, 還是玩法可以定案, 進打磨做成完整的小遊戲?」
   - 再深掘 → `continue`; 定案 → `next`(會問他打磨要以哪款為底, 寫進 feedback.md); 不玩了 → `end`

## 整理
feedback.md 依機制分段: 喜歡 / 不喜歡 / 沒感覺, 每條附原話與理由。若進打磨, 寫明選定的底版款。
