# 訪談指引: 探索階段

目的: 找出使用者**想要什麼體驗、不想要什麼體驗**, 以及這些體驗是從哪個機制來的。

## 原則
- 一次問一題, 等他回答再追問。純文字對話, 不用選單
- 問體驗, 不問機制: 先讓他講感受, 再一起追到機制。不要先說「這款是要驗證 X」, 會引導他
- 他講得籠統(「還不錯」「有點怪」)就追問具體時刻: 「哪一刻覺得 X?」「當時畫面上發生什麼事?」
- 他講到的感受, 你用自己的話覆述一次確認(「所以是 A 的時候覺得 B, 對嗎?」)

## 問題主線(依序, 可依回答調整)
1. 「哪一款給你比較好的體驗? 是什麼樣的體驗?」
2. 「那個感覺是在什麼時候出現的?」→ 追到具體的操作或事件(這就是機制)
3. 「有沒有哪裡玩起來不舒服、不好的體驗?」每款都要問到
4. 「你覺得那個不好的感覺是從哪裡來的?」
5. 對他沒提到的款: 「B 款玩起來感覺如何?」至少要有一句感受
6. 最後: 「還想繼續探索其他玩法方向, 還是差不多可以往深掘走了?」
   - 繼續 → `continue`; 往下 → `next`; 不玩了 → `end`

## 整理
寫 feedback.md 時, 每款分段, **保留他的原話**(引號), 再附你對應到的機制。他沒講的不要補。
