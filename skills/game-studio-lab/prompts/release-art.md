# 任務: 發布 — 圖示、分享預覽圖與主色方案

這款遊戲(「$name」)要放上 PVD計畫網站。做 3 個圖示、3 個分享預覽圖、3 組主色方案, 使用者會從選擇頁挑一個。

## 請讀取
- `$release_dir/game/art/art.js`、`art/style.md`: 遊戲裡已畫好的角色與場景
- `$release_dir/interface.json`(有的話): 各繪製函式要的狀態欄位
- `$studio_refs/art-lessons.md`
- `$release_dir/options/redo-notes.md`(有的話): 使用者看過上一批方案後的意見, 這批要照著改

## 要做的事
所有檔案寫在 `$release_dir/options/`。

1. **繪製頁**: `icon-a.html`、`icon-b.html`、`icon-c.html`(512×512)與 `share-a.html`、`share-b.html`、`share-c.html`(1200×630)。每頁:
   - `<meta charset="utf-8">`、`body{margin:0;overflow:hidden}`、一個剛好等於頁面尺寸的 canvas
   - 以相對路徑載入 `../game/art/art.js`, **沿用遊戲裡的角色與場景繪製函式重新排版**(放大主角、組合場景元素、換構圖), 不生圖、不用遊玩截圖; 需要補的背景、光暈、框線可以在繪製頁裡自己畫
   - **不載入音效**(不引用 audio/、sound.js), 不用計時器做動畫: 載入後立即畫好一張靜態畫面
2. **圖示**: 不透明背景, **不放任何文字**; 網站會裁成圓角加粗框、縮到 30–150 px 顯示, 重要內容放在中間約 80%, 四角只放背景; 主體要大、輪廓要清楚, 縮到 30 px 還認得出
3. **分享預覽圖**: 角色與場景重新排版, **加上遊戲名稱「$name」**, 字要大且清楚(縮成社群貼文的小卡也讀得到), 名稱與畫面不互相擋住
4. 三個圖示彼此要明顯不同(主角不同、構圖不同或場景不同), 三個預覽圖也一樣; 不要只是換顏色
5. **主色**: `colors.json`, 3 組: `[{"id": "1", "bg": "#色碼", "fg": "#2d2144 或 #ffffff", "note": "一句理由"}, ...]`。bg 是網站卡片選中時的底色, 優先從 #f29cac 粉、#aaefd5 薄荷、#4776c3 藍、#e0c64f 金挑, 也可依遊戲配色另提; fg 是卡片上的字色, 依對比選深色 #2d2144 或白色 #ffffff
6. **禁止啟動瀏覽器**(見共同守則)。用 Node vm + 假 canvas 載入每張繪製頁的腳本自測不拋錯; PNG 由流程另外輸出

## 回報
三個圖示、三個預覽圖各自的構圖重點(各一句), 三組主色的理由; 寫了哪條經驗提案(沒有就說無)。
