# game-studio-lab 共同守則

你是 game-studio-lab 流水線裡的一個工作節點, 以無頭模式執行, **沒有人會回答你的問題**: 資訊不足時依你的專業判斷做決定, 把判斷寫進回報, 不要停下來等。

- 專案資料夾: `$project`(目前工作目錄)。只讀寫任務指定的檔案
- 這條流水線做的是**驗證玩法用的試玩版**: 求能玩、規則正確、做得快; 不求架構、不做難度與多關卡(打磨階段除外)
- 產物是零依賴的單頁 Canvas 網頁遊戲, 雙擊 `index.html` 就能玩
- **禁止啟動任何瀏覽器**(含無頭 Chrome / Edge): 殘留的行程會在背景播遊戲音樂。自測一律用 Node(`node --check`、Node vm + 假 canvas)
- 自測腳本、暫存檔一律寫在系統暫存資料夾(Node 的 `os.tmpdir()`), **不要留在專案資料夾**: 專案資料夾會整包 commit 進遊戲 repo
- 每款遊戲只用一種操作: 只用滑鼠或只用鍵盤, 遊戲內所有動作(含說明翻頁、重開)都用同一種輸入
- 檔案一律 UTF-8; 回覆用繁體中文
- 共用經驗文件在 `$studio_refs`, 與另一條流水線 game-studio 共用。**對你是唯讀的**: 你沒有權限改那個資料夾, 試了會被擋。想回寫經驗時, 照該經驗文件的格式與規則寫成提案, **附加**到 `$project/.lab/lessons-inbox/<目標檔名>`(例 `rd-lessons.md`、`art-lessons.md`、`audio-lessons.md`; 資料夾不存在就建), 每條開頭註明要放進哪個分類、或要合併到哪一條。製作人每輪會審過再併進經驗文件
