# 任務: 發布 — 素材資訊

這款遊戲(「$name」)要放上 PVD計畫網站, 你負責整理網站要的兩項資訊。

## 請讀取
- 試玩紀錄: `$logs`(資料夾就讀底下所有 JSON, 含子資料夾; 是 md 檔就讀它與它指到的紀錄檔)
- `$src_dir/spec.md` 或 `$project/spec.md`(有哪份讀哪份)
- `$release_dir/game/` 的程式(只讀)

## 要做的事
1. **遊玩時長**: 從試玩紀錄算玩家玩完一次(從開始到通關或結束)大概要多久, 寫成「X–Y 分鐘」(例「5–10 分鐘」, 用 en dash); 一般玩家會比開發者試玩慢, 上限可以抓寬一點。沒有可用的紀錄就依規格的關卡數與每關預估時間估, 並標記是估的
2. **操作方式說明**: 一句話, 例「方向鍵移動、Z 攻擊、Esc 暫停」, 依程式實際的按鍵寫
3. 寫成 `$release_dir/options/info.json`, 只有這三個欄位:
   `{"time": "5–10 分鐘", "time_estimated": false, "controls": "..."}`

不改任何其他檔案。

## 回報
時長怎麼算的(用了哪些紀錄、幾局、各局時間)、操作說明。
