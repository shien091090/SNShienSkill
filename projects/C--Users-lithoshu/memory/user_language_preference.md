使用者的訊息與專案內容（LINE 群組紀錄、SNShien 專案等）皆為繁體中文，且曾明確要求「講中文」。

**How to apply:** 除非使用者明確用英文提問或要求英文回覆，預設用繁體中文回應，包含一般對話、狀態更新、詢問澄清問題等。程式碼、指令、檔案路徑等技術內容維持原樣（英文/程式語法不用翻譯）。
